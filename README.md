# LeetCode Solutions

43 problems solved, each in its own directory with the original problem statement alongside the solution.

**10 easy · 21 medium · 12 hard** — mostly Python, with one Java.

The weighting is deliberate: 21 medium and 12 hard against 10 easy. Easy problems stop teaching you much fairly quickly.

---

## Layout

Each problem is a directory named `<number>-<slug>`:

```
15-3sum/
  README.md    the problem statement, as posted
  3sum.py      the solution
```

Synced from LeetCode, so the statement always matches the version the solution was written against.

## Recurring patterns

Worth reading as groups rather than one at a time — the same idea shows up repeatedly:

| Pattern | Problems |
|---|---|
| Two pointers | 3Sum, 3Sum Closest, 4Sum, Container With Most Water, Reverse String |
| Sliding window | Longest Substring Without Repeating Characters, Substring with Concatenation of All Words, Get Equal Substrings Within Budget |
| Backtracking | Sudoku Solver, Subsets, Palindrome Partitioning, Letter Combinations, Permutation Sequence, The Number of Beautiful Subsets |
| Dynamic programming | Climbing Stairs, Word Break II, Regular Expression Matching, Student Attendance Record II, Longest Valid Parentheses |
| Linked lists | Add Two Numbers, Merge k Sorted Lists, Reverse Nodes in k-Group |
| Greedy | Hand of Straights, Distribute Coins in Binary Tree, Append Characters to Make Subsequence |
| String parsing | String to Integer (atoi), Valid Number, Zigzag Conversion, Integer to Roman, Roman to Integer |

The hard ones worth a look: **Median of Two Sorted Arrays** (binary search on the partition, not the values), **First Missing Positive** (constant space by using the array as its own hash table), and **Reverse Nodes in k-Group**.
