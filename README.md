## 📌 About

This repo contains my personal solutions to LeetCode problems, organized by problem number. Each folder includes the problem solution with comments explaining the approach, time complexity, and space complexity.

> **Goal:** Consistent daily practice — one problem at a time, building pattern recognition across topics.

---

## 🗂️ How to Navigate

Each problem has its own folder named `<id>-<problem-slug>/`, e.g. `1-two-sum/`. Inside you'll find the solution file(s).

```
leetsolutions/
├── 1-two-sum/
├── 2-add-two-numbers/
├── 3-longest-substring-without-repeating-characters/
├── ...
└── <id>-<problem-name>/
```
